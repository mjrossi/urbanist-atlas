# /about page + newspaper-style 404 — implementation plan (slice #15)

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Use `superpowers:test-driven-development` for every code-bearing step.

**Goal:** Ship the `/about` content page and a newspaper-style 404 wired via `errorElement` on the root route, both reusing the existing `.page` broadsheet vocabulary. One new CSS utility class (`.not-found-return`) for the small-caps homepage return link.

**Architecture:** Two new pure-content route components in `web/src/routes/` (no `useQuery`, no router hooks beyond `Link`). The 404 component wires as `errorElement` on the root route via a tiny `NotFoundWithLayout` wrapper in `router.tsx` that reconstructs the masthead/nav/footer chrome (because `errorElement` renders *instead of* the root component, not as a child of it).

**Tech Stack:** React 19, Vite 6, TypeScript strict, react-router v7, Vitest + RTL. **No new dependencies.**

**Spec:** [`docs/superpowers/specs/2026-05-18-about-404-design.md`](../specs/2026-05-18-about-404-design.md). Read §1 (routes/pages) and §2 (router wiring) before starting.

- [ ] **Step 2.3: Implement `NotFound.tsx`**

  Path: `web/src/routes/NotFound.tsx`

  ```tsx
  import { Link } from 'react-router';

  /**
   * Newspaper-style 404. Wired as `errorElement` on the root route in
   * router.tsx, which means it renders for any unmatched URL **and**
   * for unhandled errors thrown anywhere in the route tree.
   *
   * Reuses the `.page` single-column treatment so the masthead, nav,
   * and footer chrome stay visible — that requires the root route's
   * `errorElement` to wrap this component in the same layout `App`
   * provides (see `NotFoundWithLayout` in router.tsx).
   */
  export function NotFound() {
    return (
      <div className="page">
        <header className="page-header">
          <h1>Page not in this edition.</h1>
          <p>
            <em>
              The story you were looking for could not be found in our
              directory.
            </em>
          </p>
        </header>
        <section>
          <p>
            We retract the link, with apologies. The page you tried to reach
            either never went to press or has since been pulled from the
            directory.
          </p>
          <p>
            <Link to="/" className="not-found-return">
              Return to the front page
            </Link>
          </p>
        </section>
      </div>
    );
  }
  ```

- [ ] **Step 2.5: Wire `errorElement` in `router.tsx`**

  Modify: `web/src/router.tsx`

  Add a local `NotFoundWithLayout` component that reconstructs the chrome `App` provides (because `errorElement` renders **instead of** the root route's `Component`, not as a child of it). Wire it as `errorElement` on the root route.

  Final state of `router.tsx`:

  ```tsx
  import { createBrowserRouter } from 'react-router';
  import { App } from './App.tsx';
  import { BroadsheetNav } from './components/BroadsheetNav.tsx';
  import { Footer } from './components/Footer.tsx';
  import { Masthead } from './components/Masthead.tsx';
  import { About } from './routes/About.tsx';
  import { Browse } from './routes/Browse.tsx';
  import { Home } from './routes/Home.tsx';
  import { Metro } from './routes/Metro.tsx';
  import { NotFound } from './routes/NotFound.tsx';
  import { Results } from './routes/Results.tsx';

  /**
   * The site's route tree. Home and Results landed in slices #11 + #12;
   * Browse and Metro in slice #14; About and the newspaper-style 404
   * land in slice #15.
   *
   * `errorElement` on the root route catches both unmatched URLs (404)
   * and any unhandled error thrown by a descendant route's component
   * or loader. It renders instead of `App`, so we reconstruct the
   * masthead/nav/footer chrome in `NotFoundWithLayout` to keep the
   * broadsheet shell visible on the 404 surface.
   */
  function NotFoundWithLayout() {
    return (
      <>
        <Masthead />
        <BroadsheetNav />
        <main>
          <NotFound />
        </main>
        <Footer />
      </>
    );
  }

  export const router = createBrowserRouter([
    {
      path: '/',
      Component: App,
      errorElement: <NotFoundWithLayout />,
      children: [
        { index: true, Component: Home },
        { path: 'r/:postalCode', Component: Results },
        { path: 'browse', Component: Browse },
        { path: 'm/:metroSlug', Component: Metro },
        { path: 'about', Component: About },
      ],
    },
  ]);
  ```
