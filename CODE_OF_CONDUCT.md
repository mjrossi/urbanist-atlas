# Code of Conduct

This project adopts the [Contributor Covenant][cc], version 2.1,
as its code of conduct. See [the full text][cc-21] for details;
the key points are summarized below.

## In short

- Treat everyone with respect. Assume good faith.
- Disagreement is fine; personal attacks are not.
- This is a volunteer project — keep the tone collegial.

## Scope

Applies to all project spaces: this GitHub repository (issues,
pull requests, discussions), commit history, and any future
project-affiliated venues. Also applies when an individual is
representing the project in public.

## Enforcement

Reports of unacceptable behavior should go through GitHub's
[private vulnerability reporting][gh-pvr] on this repository (the
same channel as [`SECURITY.md`](./SECURITY.md)) so the conversation
stays private until resolved. Open a public issue only if you
specifically want a public discussion.

All complaints will be reviewed and investigated promptly and
fairly. The maintainer is obligated to respect the privacy and
security of the reporter.

## Consequences

Project maintainers who do not follow or enforce the Code of
Conduct in good faith may face temporary or permanent
repercussions as determined by other project leadership.

For specific enforcement guidelines (Correction, Warning,
Temporary Ban, Permanent Ban), see the Contributor Covenant's
[full enforcement guidelines][cc-enforcement].
